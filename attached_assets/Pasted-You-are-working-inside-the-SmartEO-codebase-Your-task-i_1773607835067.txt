==================================================

- what the previous “What’s Next” priorities were
- what appears to have actually been completed
- what remains open / unresolved
- what the next logical priorities should be now

In other words:
- Previous report says goals
- Current data says what got done
- System decides what carries forward and what is next

Implement this carefully.

Suggested logic:
- Parse previous report sections into normalized structured objects
- Compare prior “What’s Next” items against:
  - Airtable statuses
  - content publication/update timestamps

  - partially completed
  - still pending
  - no longer relevant

- Never blindly repeat the last report’s next steps
- Never ignore the last report entirely

If a prior report is missing, the system should gracefully fall back to current-source-only generation.
