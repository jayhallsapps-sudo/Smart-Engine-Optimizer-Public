# SOP: New Service Page Creation (SEO)

**Purpose**: Create new, research-backed service pages that align with search intent and existing site structure.

**Scope**: Applies to net-new service pages only.

---

## Process

### Step 1: Page Setup
- Clone an existing published service page in WordPress
- Locate the new draft (sort by Date Last Modified if needed)

---

### Step 2: Research & SERP Validation (Required)
- Review the top 3 non-Wikipedia SERP results for the service keyword
  - Use Ahrefs Keyword Overview
- Identify:
  - Core subtopics competitors cover
  - Required trust elements (credentials, process, FAQs)
- Research:
  - 1–2 authoritative external sources if relevant
  - Industry standards, guidelines, or definitions
  - No direct competitors

---

### Step 3: Rewrite for Target Service
- Copy the entire cloned service page content into the client's Claude project
- Rewrite to target the new service keyword:
  - Maintain existing section structure
  - Update copy to reflect researched intent and terminology
- Add links:
  - **External links**: Only where they support credibility (1–2 MAX)
  - **Internal links**: Include links to related services only

---

### Step 4: Build the Page in WordPress
- Paste revised copy into the page template
- Add image(s) as needed — use keyword-aligned alt text
- Ensure:
  - Clean, keyword-only URL
  - SEO title and meta description are set
  - CTA exists above the fold

---

### Step 5: Before You Hit Publish
Confirm on the live page:
- CTA above the fold
- Logical heading structure
- Accurate, helpful content aligned with search intent
- Image alt text present and descriptive
- SEO title and meta description are correct
- All links resolve correctly

> **Fix all issues before proceeding.**

---

### Step 6: Internal Linking (Post-Publish)
- Add links to the new service page from **at least 3 relevant existing blogs**
- Use contextual, non-generic anchor text

---

### Step 7: Finalize & Log
- Post the live URL in the client Slack channel
- Return to Airtable and:
  - Update status to **Live**
  - Add Published Date
  - Remove due date
