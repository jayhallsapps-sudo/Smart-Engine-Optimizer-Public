Refactor the QBR Prep Section 2 “Top Converting Pages” table so it matches the intended structure and produces stronger, more client-useful analysis.

Problem:
The current Top Converting Pages table has multiple issues:
- the Conversion Source column is being used for long fallback explanations instead of real source attribution
- “Manual entry needed” is appearing in rows where it should not
- Notes / What We’re Learning is repetitive and generic
- event/action context like Phone Clicks or VOB Form Start is not being placed correctly
- source attribution should display as a badge next to the Type, not as a full separate explanation column

The current output is structurally wrong and too weak analytically.

==================================================
NOTES / WHAT WE’RE LEARNING RULES
==================================================

This is the most important quality fix.

Current problem:
The notes are too repetitive and generic, like:
- High-intent service page. —% CVR.
- Direct admissions path. —% CVR.

That provides almost no value.

Expected:
Each note should be specific to the page/pattern and give distinct strategic insight.

Good examples:
- Strongest trackable conversion on the site; client confirmed fast, quality leads from this form
- Primary GMB landing page; dominant call driver but attribution drops to (not set)
- High-intent pre-call behavior; users vetting before committing
- Only non-homepage service page generating call clicks
- Luxury buyers researching clinical credibility before calling

Rules:
1. Notes must differ meaningfully row to row.
2. Notes should explain behavior, not just restate the page type.
3. If a page is fallback-only and not directly tracked, the note should still offer useful strategic interpretation without pretending certainty.
4. Avoid generic filler like:
   - high-intent page
   - likely conversion page
   - unclear
   - manual entry needed
   unless absolutely unavoidable
5. If CVR is not available, do not force “—% CVR” into every row.

==================================================
ANALYSIS LOGIC
==================================================

Build row-level notes using the strongest available signals:
- GA4 event type
- call-tracking source / landing page behavior
- page class
- page role in the funnel
- service/admissions alignment
- known business intent
- whether the page is homepage / FAQ / staff / service / form entry

Examples:
- Form page + GA4 form_start → strongest trackable on-site conversion
- Homepage + CTM/GA4 phone clicks → dominant top-funnel or GMB-assisted call driver
- FAQ page + phone clicks → pre-call vetting behavior
- Service page + phone clicks → direct service-intent conversion behavior
- Staff page + phone clicks → trust/credibility research before contact

The goal is a polished client-facing table, not a debug table.
