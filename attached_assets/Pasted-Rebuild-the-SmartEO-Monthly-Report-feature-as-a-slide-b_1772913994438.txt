==================================================
DATE LOGIC
==================================================

Switch Monthly to true calendar month reporting wherever the source supports it.

For a selected report month:
- analysis window = first day of selected month through last day of selected month
- comparison window = prior calendar month

Example:
- selected month: March 2026
- analysis window: 2026-03-01 through 2026-03-31
- comparison window: 2026-02-01 through 2026-02-28

Do NOT use rolling last_30_vs_prev_30 for the final Monthly product when the connected source can support actual calendar month windows.

Use actual calendar month for:
- GSC where supported by integration
- GA4 where supported by integration
- Call tracking where supported by integration
- Airtable
- Asana
- GBP where supported

If a source cannot support exact month windows in the current integration:
- use the best available fallback
- document that fallback in code clearly
- do not fake calendar precision
