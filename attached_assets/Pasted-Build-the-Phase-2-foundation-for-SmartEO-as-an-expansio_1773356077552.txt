Build the Phase 2 foundation for SmartEO as an expansion of the existing product, not as a rebuild from scratch.

Critical rule:
Use as much of the existing SmartEO infrastructure, report-generation logic, components, preview/edit systems, client architecture, integrations, and styling as possible. Reuse first. Refactor only where needed. Replace only as a last resort.

Before replacing any existing feature, document whether it can be:
- reused
- wrapped
- extended
- lightly refactored

If a feature must be replaced, explicitly document:
- what the existing feature is
- why it cannot reasonably be reused
- why extension or light refactor is insufficient
- what the replacement solves that the current version cannot
