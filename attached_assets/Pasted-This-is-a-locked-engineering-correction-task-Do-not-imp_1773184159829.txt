PART B — TOP CONVERSION PATTERNS: EVIDENCE COLUMN

CURRENT FAILURE

Pattern and Why It Matters are acceptable.
Evidence is still too weak because it reads like generic implementation advice instead of an inference from the data.

REQUIRED FIX

Where Evidence is not directly verified by hard event data, it must be written as inference.

The Evidence column must explicitly signal that the statement is inferred, directional, or confidence-weighted.

Allowed prefixes:

Inference:

Directional inference:

Moderate-confidence inference:

High-confidence inference:

Low-confidence inference:

Do not leave evidence as plain declarative fact if it is not directly verified.

Evidence must explain what the available data suggests.

Good pattern:
“Inference: Treatment-intent organic traffic is likely the strongest conversion-support pattern because these queries sit closest to admission decision-making, even though page-level GA4 conversion verification is incomplete.”

Another good pattern:
“Moderate-confidence inference: Tracking gaps appear to be suppressing visibility into true conversion behaviour because high-intent entry patterns are present but page-level event confirmation is incomplete.”

Bad pattern:
“GA4 event tracking is not yet confirmed on key pages — connect GA4 or call tracking to qualify conversion-driving pages.”

Why bad:
Because that is implementation advice, not evidence.

Hard rule:
Evidence should describe what we think the pattern means.
Implementation advice belongs elsewhere, not as the whole evidence statement.
