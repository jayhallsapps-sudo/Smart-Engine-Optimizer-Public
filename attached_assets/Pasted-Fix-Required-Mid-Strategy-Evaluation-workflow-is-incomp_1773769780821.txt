Fix Required: Mid-Strategy Evaluation workflow is incomplete and currently wrong

The current implementation is not acceptable. It built empty tables instead of the automated workflow requested.

What is wrong right now

Current behavior:

I select the client

I name the evaluation batch

I land in empty tables

the system expects manual data entry

there is no Screaming Frog upload entry point in the expected workflow

there is no Generate Evaluation action

competitor data is not auto-pulled from the client info section

That is not the required behavior.

The Evaluation Sheets module must not behave like a blank spreadsheet editor. It must behave like an automated evaluation generator.

Required behavior
Correct user flow

When I create a new evaluation batch, the workflow must be:

Select client

Auto-load competitor list from the Client Info section under competitors

Enter evaluation batch name

Upload Screaming Frog crawl export

Click Generate Evaluation

System automatically:

parses Screaming Frog upload into Crawl Data

pulls competitor benchmark data from integrations

fills Main Evaluation automatically

fills Clicks Distribution automatically

fills Traffic Distribution automatically

calculates derived metrics automatically

calculates rankings automatically

saves the populated evaluation batch

I should not have to manually type values into the evaluation sheets.

Functional fixes required now
1. Client selection must auto-pull competitors

When a client is selected, the system must fetch the competitor list from that client’s stored Client Info record.

Expected source:

Client Info → competitors

Required behavior:

auto-populate competitor rows in Main Evaluation from stored competitors

include the selected client as the first row

do not make me manually add competitor rows unless I choose to override

If no competitors exist in Client Info:

show a clear warning state

allow manual add only as a fallback

2. Add Screaming Frog upload directly in batch creation flow

After selecting client and naming the batch, I need a visible upload area for Screaming Frog.

Required:

upload control in the creation/setup step, not buried later

accepted file types: CSV and XLSX if supported

store uploaded file as crawl source for this batch

parse after upload

show success/failure state

This should be part of the standard setup flow.

3. Add Generate Evaluation button

There must be a primary CTA button:

Generate Evaluation

Clicking this button should run the full population workflow.

This is the missing orchestration layer.

4. Generate Evaluation must populate all sheets

When Generate Evaluation is clicked, the system must:

Main Evaluation

Auto-fill:

client row

competitor rows from Client Info

WHOIS / archive data

Ahrefs data

SEMrush data

derived metrics

rank columns

summary rows

Crawl Data

Auto-fill:

parsed SF rows

enriched fields from GSC / GA4 / Ahrefs / SEMrush where needed

Clicks Distribution

Auto-generate from:

Crawl Data category mapping

GSC URL data

Traffic Distribution

Auto-generate from:

Crawl Data category mapping

GA4 URL/session data

No manual metric entry.

5. Empty tables should never be the first state after setup

After batch creation, the default experience should not drop me into blank editable grids.

Instead:

before generation: show setup panel with client, competitors preview, SF upload, and Generate button

after generation: show populated tabs

If generation has not yet been run, each tab should clearly say something like:

“No evaluation generated yet. Upload Screaming Frog and click Generate Evaluation.”

Do not present blank spreadsheet tables as though manual entry is expected.

6. Preserve manual editing only after generation

Editable cells are fine, but only after the system has generated the baseline data.

Correct model:

generation first

manual adjustment second

Not:

blank table first

user does all the work

selected client

batch name
