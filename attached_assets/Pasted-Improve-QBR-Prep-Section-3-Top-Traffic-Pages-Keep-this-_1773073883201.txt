FIX 1 — CONNECTION TO ADMITS
==================================================

Current problem:
Almost every row shows “Unclear,” which makes the column useless.

Replace the current logic with a more useful classification model.

Use one of these values:
- Direct
- Assisted
- Trust / Evaluation
- Informational
- Limited attribution

Decision guidance:
- Direct:
  page is clearly tied to conversion behavior, admissions, contact, VOB, or high-intent service action
- Assisted:
  page likely supports the conversion path but is not the final action point
- Trust / Evaluation:
  page supports credibility/research before action, e.g. staff/team/about style pages
- Informational:
  page drives awareness/education traffic with weak direct admit linkage
- Limited attribution:
  page may matter, but the available data cannot confidently connect it to admits

Do NOT overuse “Limited attribution.”
Use it only when the page truly cannot be interpreted more specifically.

==================================================

Current problem:
The Insight column is mostly just page classification, e.g.:
- Substance-Specific page
- Homepage page
- Conditions page

That is not enough.

Replace it with a real interpretation of the page’s role.

Examples of better insight logic:
- High-volume informational entry point with weak direct admit linkage
- Awareness-stage content that may support later service-page exploration
- Trust-building page that can influence late-stage decision-making
- Branded/local entry page with likely assisted conversion role
- Condition-specific page that should route users toward appropriate service pages
- Service-adjacent page with stronger support value than direct conversion value

Rules:
1. Insight should explain the page’s role, not just its category
2. It should vary meaningfully row to row
3. It should be client-readable and useful
4. Avoid repetitive low-value phrasing
