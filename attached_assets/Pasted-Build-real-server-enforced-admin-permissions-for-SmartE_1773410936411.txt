- ADR

- Account Manager

Requirements:

Do not overbuild enterprise auth if the current product does not need it yet.

Use the cleanest path that fits current SmartEO architecture, such as:
- real user/session role from backend

Do not keep localStorage as the source of truth for permissions.

5. PRESERVE CURRENT PRODUCT FLOW

Requirements:
- do not break existing workflow/report functionality
- do not rebuild login/account systems unnecessarily
- extend the current system in the least disruptive way
- keep internal use smooth
