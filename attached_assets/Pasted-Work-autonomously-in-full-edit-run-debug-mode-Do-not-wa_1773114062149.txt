Critical protection rule for QBR Prep:
QBR Prep is protected and should not be reworked, restructured, or “improved” unless a change is clearly non-destructive and strictly necessary for shared-system stability.

Allowed QBR Prep changes:
- truly non-destructive shared infrastructure updates that do not alter its logic, layout, wording, field behavior, or report output
- compatibility fixes required because of shared code changes
- bug fixes only if something is already clearly broken and the fix preserves intended behavior

Disallowed QBR Prep changes:
- changing content structure
- changing section order
- changing text generation behavior
- changing prompt logic
- changing editable field behavior
- changing layout or styling unless required by a shared rendering fix
- opportunistic refactors
- standardization for the sake of consistency
- any change made just because another report uses a different pattern

If there is doubt, do not modify QBR Prep. Prefer leaving QBR Prep untouched.
