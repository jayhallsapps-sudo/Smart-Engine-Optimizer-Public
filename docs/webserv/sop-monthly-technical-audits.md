# SOP: Monthly SEO Technical Audits

**Goal**: Build confidence and consistency in reviewing technical audits, prioritizing SEO work within client scope, and clearly communicating risks, quick wins, and larger opportunities.

This task supports core AM responsibilities around technical SEO ownership, strategic prioritization, project management, and client communication.

---

## Step 1: Schedule Technical SEO Work

Before running or reviewing any audit, ensure technical SEO work is planned and visible.

**What to Do**:
1. In the client's Asana project, create a dedicated "Technical SEO" section (if one does not already exist)
2. Add a recurring Monthly "Technical SEO Review" task
3. Frequency should align to client scope
4. Duplicate & schedule this task out for the remainder of the client's contract
5. Every task must include a due date — no placeholder or unscheduled tasks

**Expectation**: Leadership should be able to open the Asana project and clearly see:
- When technical SEO is reviewed
- How often it happens in line with scope for the client
- That it is planned through the full contract term

---

## Step 2: Run & Review SEMrush Site Audit

For the current Technical SEO Review task:
1. Run or refresh the SEMrush Site Audit so it is recent within 24 hours
2. Review Errors, Warnings, and Notices
3. Focus on issues that impact:
   - Crawlability & indexation
   - Rankings & visibility
   - Site performance & UX

---

## Step 3: Prioritize Issues Within Client Scope

### Export the Issues Table in SEMrush
1. Open the SEMrush Site Audit
2. Click into the Issues table
3. Click Export (top right)
4. For the report type, select Issues

This CSV export should include:
- Issue ID
- Issue Type (Error / Warning / Notice)
- Issue Name
- Failed Checks
- Total Checks
- Changed from Last Audit

### Upload the Export to the Client's Technical SEO Tracking Sheet
- One Google Sheet per client in their SEO client folder
- One tab per month (e.g. Jan 2026)
- Copy the export into that monthly tab
- Do not modify or delete any of the exported columns

### Classify and Summarize Each Issue
In the same tab, add the following columns to the right of the export:

| Column | Options |
|--------|---------|
| Issue Category | Crawlability, Indexation, Performance, On-page, Security, Content, Links, Other |
| Impact Level | High / Medium / Low |
| Status | Can Be Fixed (In Scope), Requires Larger Effort, Low Impact, Not Relevant |
| Planned Action / Next Step | Fix directly, schedule Asana task, flag to client as out of scope, monitor |
| Asana Task Link | If applicable |
| Notes | 1–2 sentences max explaining next steps |

> AMs are classifying the **issue**, not every individual page.

### Use SEMrush for Page-Level Details
- If needed, click into an issue in SEMrush to view affected URLs (focus on priority URLs: conversion points, service pages)
- Page-level analysis stays inside SEMrush
- The Google Sheet is for summary, prioritization, and tracking over time

---

## Step 4: Schedule SEO Impact Check-Ins & Client Visibility

Any technical issue that becomes an Asana task must also include a planned SEO impact review.

### Add Impact Check-In Subtasks
For each technical SEO fix that is completed, add two subtasks to the parent Asana task:
- SEO Impact Check — 3 weeks Update
- SEO Impact Check — 6 weeks Update

### Review SEO & CRO Impact
When completing each impact check-in:
- Use Looker Studio (CRO / SEO tracking views) to review: page performance, organic visibility signals, engagement/conversion indicators (where applicable)
- Compare performance pre- vs post-fix where possible
- Note whether the change shows: Positive impact, Neutral impact, or Needs more time (schedule follow-up in 2–3 weeks)

### Document the Outcome
In the subtask, add a short written update summarizing:
- What was implemented
- What changed (or didn't yet)
- What the next step is (monitor, iterate, expand)

Keep this concise and client-safe.

### Loop Into Client Reporting
Surface meaningful outcomes in the appropriate client-facing touchpoint:
- **Bi-weekly report** → if impact is quick or notable
- **Monthly report** → if impact is broader or trend-based

Clearly communicate: what was done, why it mattered, what impact we're seeing (or tracking).

---

## What Success Looks Like

1. All issues are clearly categorized, prioritized, and assigned a status
2. In-scope issues are scheduled in Asana, next steps and SEO impact is tracked and reported to the client in a timely manner
3. Larger efforts and risks are clearly flagged
4. Month-over-month changes are visible via "Changed from Last Audit"
5. Anyone reviewing the sheet can quickly see:
   - What issues exist
   - What we're fixing
   - What we're flagging
   - What we're intentionally deprioritizing
