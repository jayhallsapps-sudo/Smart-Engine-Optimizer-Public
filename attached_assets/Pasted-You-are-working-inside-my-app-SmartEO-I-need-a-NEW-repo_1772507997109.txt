You are working inside my app (SmartEO). I need a NEW report type called “QBR Prep”.

Goal:
Generate a single Google-Doc-ready report that identifies opportunities for improvement based on the previous quarter (or previous quarter “to date”) and prepares priorities for the next quarter. The output is NOT a slide deck. It is a structured document with categorized opportunity lists.

UI / Inputs:
- client_id (required)
- past_quarter (required): one of [Q1, Q2, Q3, Q4, Q1_TODATE, Q2_TODATE, Q3_TODATE, Q4_TODATE]
- future_quarter (required): one of [Q1, Q2, Q3, Q4]
- optional toggles (default true): include_content, include_technical, include_local, include_cro, include_authority, include_tracking
- opportunity_cap_per_category (default 10)
- timezone (default from client settings)

Quarter-to-date logic:
- Quarter date boundaries are calendar quarters in the client timezone.
- Q1 = Jan 1–Mar 31, Q2 = Apr 1–Jun 30, Q3 = Jul 1–Sep 30, Q4 = Oct 1–Dec 31.
- Qx_TODATE means quarter start date → “today” (now in client timezone).
- past_quarter defines the analysis window (past_start, past_end).
- future_quarter defines the planning window label only (no data pull required for future quarter; it’s for headings/roadmap framing).

Data sources available (use best source for each):
- Google Analytics 4 (GA4) for sessions, engagement, conversions (forms), conversion rate, landing page performance, device split.
- Google Search Console (GSC) for clicks, impressions, CTR, average position; query and page performance.
- Call tracking (CallRail or CTM) for call counts, call source attribution (GBP vs organic vs other), outcomes/tags (VOB/VVOB/qualified) when available, missed/answered if available.
- Google Business Profile (GBP) for interactions (calls, website clicks, directions), posts, reviews, photos if available.
- Screaming Frog imports for crawl diagnostics: indexability, status codes, canonicals, directives, metadata, headings, internal linking depth/inlinks, orphan risk, etc. Use Crawl Overview + Internal All data if present.
- Optional: SEMrush site audit if connected (issue counts/severity) and optional authority/backlink data from Ahrefs/SEMrush only if include_authority is true AND integration is available without direct API.

Hard constraints:
- Do NOT invent metrics. If a metric is unavailable, output “Not available” and still produce an opportunity based on available evidence.
- The report must be evidence-based: each opportunity includes a data source reference field that names which system(s) produced the evidence (GA4/GSC/CallTracking/GBP/SF/SEMrush/Ahrefs).
- Keep output deterministic: same inputs → same ordering/structure.
- Do not output code. Implement changes in the app; choose your own architecture.

Output format (single document):
Return a JSON object AND a doc-ready markdown string in the response.
- JSON keys: report_title, client_name, past_window_label, past_start, past_end, future_window_label, generated_at, executive_summary, opportunity_backlog
- executive_summary: { wins: [..3], top_opportunities: [..5] }
- opportunity_backlog: array of categories; each category has category_name and opportunities[] (capped by opportunity_cap_per_category)

Document structure (markdown string):
1) Title: “QBR Prep – {client_name} – {past_window_label} → Plan for {future_window_label}”
2) Executive Summary (max 10 lines total):
   - “Top Wins (QTD/Qx)” (3 bullets)
   - “Top Opportunities for Next Quarter” (5 bullets, each includes Category + expected KPI impact)
3) Opportunity Backlog (grouped sections in this exact order if enabled):
   A. Content Opportunities
   B. Technical SEO Opportunities
   C. Local / GBP Opportunities
   D. CRO / Conversion Opportunities
   E. Authority / Links Opportunities (optional)
   F. Tracking / Measurement Opportunities
Each category section contains numbered items (1..N) with the following fields in this exact order:
- Opportunity Title:
- Priority: (P0/P1/P2)
- Impact: (High/Med/Low)
- Effort: (S/M/L)
- KPI Affected: (Calls, Forms, CTR, Rankings, Indexation, GBP Actions, Tracking Integrity)
- URL(s):
- Evidence: (source + key metric values/deltas)
- Problem:
- Opportunity:
- Why it matters:
- Recommended next step:

Opportunity scoring rules (must implement):
Define a simple scoring model that produces Priority, Impact, Effort, and ordering within each category. Use these rules:

Priority (P0/P1/P2):
- P0: materially affects conversions/leads OR blocks indexing/crawling on money pages OR severe tracking break.
- P1: meaningfully improves rankings/CTR/conversion rate with moderate confidence and/or impacts high-traffic pages.
- P2: nice-to-have improvements, smaller pages, or lower confidence.

Impact (High/Med/Low):
- High: affects top 20 landing pages by traffic or conversions OR affects sitewide templates OR affects GBP call volume materially OR blocks indexation of key pages.
- Med: affects mid-tier pages or a subset of templates; measurable but smaller.
- Low: limited scope or uncertain measurable lift.

Effort (S/M/L):
- S: metadata tweaks, internal links, minor copy edits, GBP post cadence, fixing a handful of URLs.
- M: content refresh requiring section expansion, multiple page edits, moderate technical fixes.
- L: template/dev work, architecture, large-scale content creation, tracking overhaul.

Category-specific opportunity generation rules:

A) Content Opportunities (use GSC + GA4 + Call Tracking):
Generate candidates using these heuristics (pick best available; cap results by importance):
1. High impressions, low CTR:
   - GSC pages or queries with impressions above median AND CTR below site median.
   - Prioritize avg position 1–10 and 11–20.
   - Opportunity: rewrite title/meta, improve snippet alignment, add FAQ/TLDR, adjust H2 structure.
2. Striking distance pages:
   - GSC pages with avg position 4–15 and impressions trend up, clicks lag.
   - Opportunity: refresh content, expand intent coverage, add internal links from relevant pages.
3. High traffic, low conversions:
   - GA4 landing pages in top 20 organic sessions with conversion rate below site average.
   - Opportunity: CRO improvements, CTA placement, trust blocks, intent match adjustments.
4. Conversion pages slipping:
   - Pages with conversions down QoQ/QTD while traffic stable or up.
   - Opportunity: SERP review, refresh, fix technical/UX issues.
For each content opportunity include the page URL and (if possible) the main query set from GSC.

B) Technical SEO Opportunities (use Screaming Frog + GSC Indexing; SEMrush optional):
Generate candidates with highest impact first:
1. Indexation blockers on important pages:
   - noindex, robots blocked, canonical to wrong URL, redirect chains, 4xx on key pages.
2. Internal link problems:
   - key pages with low inlinks, deep crawl depth, orphan signals if available.
3. Duplicate/weak metadata or headings:
   - duplicate titles/H1s, missing titles, multiple H1s, missing H1s; prioritize key templates/pages.
4. Broken/redirected internal links:
   - internal 3xx/4xx links affecting important pages.
5. Sitemap/index coverage anomalies:
   - GSC coverage errors, sitemap submission errors, sudden spikes in excluded.
Each technical item must list affected URL(s) and cite SF or GSC evidence.

C) Local / GBP Opportunities (use GBP + Call Tracking):
1. GBP interactions down vs prior comparable period:
   - Identify decline in calls/website clicks/directions if available.
   - Opportunities: posts cadence, photo updates, services/products completeness, Q&A, categories, review velocity.
2. GBP call attribution opportunities:
   - If call tracking shows GBP-sourced calls low relative to interactions or location importance, propose optimizations.
3. Review gaps:
   - Low review velocity or slow responses; propose a review-response and generation workflow.
Include GBP evidence and call tracking evidence.

D) CRO / Conversion Opportunities (use GA4 + Call Tracking):
1. Organic conversion rate down on key pages.
2. Device-specific issues (mobile conversion rate significantly lower than desktop on key pages).
3. High engagement but low conversion (high time/engagement rate, low calls/forms).
4. Missed/abandoned calls (if available): high missed rate suggests ops or tracking fixes.
Each CRO item must include the page URL(s) and metrics.

E) Authority / Links (optional; only if integration available under plan credits):
Use Ahrefs/SEMrush authority metrics only if available via integrations; otherwise output “Not available” and skip this category.
Candidate types:
- Important pages with weak referring domains/backlinks compared to top pages.
- Lost links to key pages.
- Linkable asset opportunities (content pieces that could earn links).
Keep to high-level actionable items with evidence.

F) Tracking / Measurement Opportunities (use GA4 + GSC + Call Tracking):
1. Missing or changed GA4 conversion events.
2. Call source attribution inconsistent, missing UTMs/gclid where expected.
3. GSC property anomalies (sharp drops likely due to tracking/property issues).
4. Discrepancies: GA4 organic conversions rising but calls falling (or vice versa) suggesting tracking gaps.
Must include evidence and recommended fix.

Ordering:
Within each category, sort opportunities by Priority (P0 before P1 before P2), then Impact, then magnitude of evidence (bigger deltas / higher traffic/conversion importance).

Wins (for Executive Summary):
Derive 3 wins from the past window:
- Examples: biggest improvement in conversions/calls, best CTR gain, best ranking gain for a key cluster, GBP call lift, major technical issue resolved.
Wins must reference evidence sources.

Top Opportunities (Executive Summary):
Select 5 opportunities across all categories:
- Prefer P0/P1 and High/Med impact; ensure variety across categories when possible.

Final deliverable:
Implement the QBR Prep report generator so when a user selects QBR Prep + quarter windows, the app produces the JSON + doc-ready markdown exactly as specified, using the data sources above and the heuristic rules. If any data source isn’t connected, still produce the report using what’s available and clearly label “Not available” where missing.
