REQUIRED FIXES
==================================================

1) STRICT PAGE-TYPE GATING

Do not allow the following to fill a core Levels of Care slot unless explicitly configured by a stronger rule:
- /blog/
- /post/
- /category/
- /categories/
- media/image/file asset URLs (.jpg, .jpeg, .png, .webp, .gif, .svg, .pdf, etc.)

Core Levels of Care slots must prefer true destination pages, not editorial/supporting content.

Examples:
- Detox slot should prefer a real detox/detoxification page
- Residential slot should prefer a real residential/inpatient page
- PHP / IOP slot should prefer a real PHP/IOP page
- Outpatient slot should prefer a real outpatient page
- Dual Diagnosis slot should prefer a real dual diagnosis page

If only blog/resource content exists for a concept, do not treat that as a confirmed core Levels of Care page.
Instead, classify it honestly as supporting content and reflect the gap in the diagnosis.

2) PAGE IDENTITY MUST USE STRONGER EVIDENCE

For a page to qualify as a core Levels of Care page, require stronger evidence than keyword presence alone.

Use a weighted identity model combining:
- URL pattern
- page title
- H1
- visible content
- nav / footer prominence
- whether the page reads like a primary service/LOC destination
- whether the page is editorial/resource content instead

Do not let a single weak match like “residential” in a blog post title cause Residential / Inpatient to be marked confirmed.

3) PRIMARY LOCATION CONSISTENCY

If the report header shows Primary Location unresolved, Section 4 must not independently assign a confident Primary Location page without using the same resolved inventory source.

Create one shared resolved page inventory and location-slot resolution outcome, then reuse it consistently in:
- report header
- Section 4
- Section 5
- Section 6
- Section 9 where relevant

No cross-section disagreement.

4) TIER 1 CONFIRMATION STANDARD

Tier 1 must not treat blog posts, blog categories, or other supporting/editorial pages as equivalent to confirmed primary Levels of Care pages.

If the only evidence for Detox or Residential is editorial/supporting content, the diagnosis must say that:
- supporting content exists
- dedicated primary Levels of Care destination page not clearly confirmed

Do not overstate.

5) SECTION 7 TARGET SANITY FILTER

Never use media-file URLs as keyword recommendation targets.

Explicitly exclude targets that are:
- image files
- media library assets
- raw CDN/media paths
- non-page assets

If the best-matching URL is a media asset, route the recommendation to:
- the parent page if that can be reliably determined
or
- create a safer optimize-existing/create-new decision using actual page URLs only

6) SECTION 7 COUNT / CAP MATH

Any summary sentence describing row count, cap, or multiplier must be mathematically consistent with the actual rendered values.

Example:
If monthly credit capacity is 8, then “2× monthly credit capacity” must mean 16, not 11.
Either:
- change the count logic
- change the wording
- or remove the multiplier phrasing if it is not actually what the section is doing

7) BLOG / RESOURCE VS LOC CLASSIFICATION

Strengthen clientReadableType / page classification so pages like:
- /post/...
- /blog/...
- /blog/categories/...
do not get promoted into core LOC slots simply because they contain treatment terms.

They may still be:
- Blog / Resource
- Supporting content
- Assisted conversion content
- Continuum-support content
But not primary LOC pages unless truly intended as such.
